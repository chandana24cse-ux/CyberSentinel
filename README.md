CyberSentinel: Responsible AI Network Intrusion & Anomaly Detection with Gemma 4

About the Project

CyberSentinel uses simulated network traffic and machine learning to detect network anomalies. Gemma 4 analyzes detected threats and provides contextual risk insights. The system promotes responsible, evidence-based cybersecurity analysis.

Key Features

 Network traffic simulation
 Machine learning-based anomaly detection
 AI-powered threat analysis using Gemma 4
 Risk assessment and incident reports
 Responsible AI principles

Technology Stack

 Python
 Machine Learning
 Gemma 4
 FastAPI
 HTML, CSS and JavaScript
